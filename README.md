# mujoco_warp_pbr

A batched, physically based renderer for [MuJoCo Warp](https://github.com/google-deepmind/mujoco_warp),
written in [NVIDIA Warp](https://github.com/NVIDIA/warp).

Work in progress. Research notes live in [`research/`](research/README.md).

## Development

```bash
uv sync --all-extras
uv run pytest
```
