# Filament (google/filament, sparse clone without third_party)

Spec: `docs/Filament.md.html` (theory), `docs/Materials.md.html` (parameters). Shaders:
`shaders/src/surface_*.fs`. IBL precompute: `libs/ibl/src/{CubemapIBL,CubemapSH}.cpp`, `tools/cmgen`.

## Pixel parameters (`surface_shading_lit.fs`)
- `diffuseColor = baseColor·(1−metallic)`; dielectric `f0 = 0.16·reflectance²` (default 0.5 →
  0.04); `f0 = baseColor·metallic + f0_d·(1−metallic)`; `f90 = 1`.
- `perceptualRoughness` clamped to [0.045, 1]; `α = pr²` (MIN_ROUGHNESS 0.002025).
- Geometric specular AA: `α² ← saturate(α² + min(2·variance·|dN|², threshold))`.
- Normal map: `n = normalize(TBN · n_ts)`; `NoV = max(NoV, 1e-4)`.
- Emissive in nits with exposure weight; AO: diffuse `min(material AO, ssao)`, specular AO
  (Lagarde) `saturate(pow(NoV+ao, exp2(−16α−1)) − 1 + ao)`, optional GTAO multi-bounce.

## BRDF (`surface_brdf.fs`)
- D_GGX: `(α / ((1−NoH²) + (NoH·α)²))² / π`.
- V_SmithGGXCorrelated: `0.5 / (NoL·√(NoV²(1−α²)+α²) + NoV·√(NoL²(1−α²)+α²))` (includes 1/(4·NoL·NoV)).
  Fast: `0.5 / mix(2·NoL·NoV, NoL+NoV, α)`.
- F_Schlick: `f0 + (f90−f0)(1−LoH)⁵`.
- Diffuse: Lambert `diffuseColor/π` (Burley optional).
- Multiscatter: `energyCompensation = 1 + f0·(1/dfg.y − 1)`, `Fr *= energyCompensation`.
- Per light: `(Fd + Fr) · lightColor · intensity·exposure · attenuation · NoL · visibility`.
- Extra lobes (not in our v1 but structure kept extensible): clearcoat (GGX + Kelemen V,
  F0 0.04), anisotropic GGX, sheen (Charlie + Neubelt), subsurface wrap, iridescence (Belcour).

## IBL (`surface_light_indirect.fs`)
- DFG LUT (NoV, pr) → (x, y, z): `E = mix(dfg.xxx, dfg.yyy, f0)`; 1024 GGX samples/texel.
- Specular: dominant dir `r = mix(reflect(−v,n), n, α²)`, `lod = maxLod·pr·(2−pr)`,
  `Fr = E · prefiltered(r, lod)`.
- Diffuse: SH9 pre-multiplied by Aᵢ/π: `E(n) = sh0 + sh1·y + sh2·z + sh3·x + sh4·yx + sh5·yz +
  sh6·(3z²−1) + sh7·zx + sh8·(x²−y²)`, `Fd = diffuseColor · E(n) · (1−E) · diffuseAO`.
- Default IBL intensity 30000 (`IndirectLight.h`).

## Lights (`surface_light_punctual.fs`, `LightManager.cpp`)
- Units: directional lux; point `I = lm/(4π)` cd; focused spot `I = lm/(2π(1−cosOuter))`.
- Falloff: `saturate(1−(d²/r²)²)² / max(d², 1e−4)` (r = falloff radius).
- Spot: `scale = 1/max(1/1024, cosInner−cosOuter)`, `offset = −cosOuter·scale`,
  `att *= saturate(dot(−dir, l)·scale + offset)²`.
- Sun disc option for directional lights.

## Exposure / tone mapping / color
- `EV100 = log2(N²/t · 100/S)`, `exposure = 1/(1.2·2^EV100)` (pre-exposed lights).
- Tone mappers: ACES legacy (default), ACES, Filmic, **PBR Neutral** (Khronos), AgX, GT7, Linear.
- sRGB OETF: `x ≤ 0.0031308 ? 12.92x : 1.055x^(1/2.4) − 0.055`.

## Takeaways
- This is our real-time BRDF/IBL/tone-mapping reference, formula for formula.
- DFG LUT + SH9 + prefiltered mips can be generated by our own Warp kernels (same math as
  `CubemapIBL.cpp`), cross-checked against `cmgen` output if we build Filament.
